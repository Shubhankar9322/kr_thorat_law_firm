# K R THORAT LAW FIRM — Homepage

This version contains only the homepage/hero experience for now.

## Disclaimer behavior
The disclaimer popup appears EVERY time the page is opened or refreshed.
There is intentionally no localStorage/cookie acceptance check.

Clicking "I Agree & Continue" closes the popup for that page session only.

## Design
The page was created from scratch for this project based on the visual direction in the supplied reference:
- beige / ivory background
- muted gold accents
- editorial legal typography
- arch/monogram visual
- subtle grid texture
- minimal navigation

It is not copied from a specific website template.
